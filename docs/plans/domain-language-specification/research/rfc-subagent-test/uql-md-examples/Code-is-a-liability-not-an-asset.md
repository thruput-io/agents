# Code is a liability, not an asset

Parent: Simplicity

New code carries a Maintainability cost across the Development Stack and delivers Value only when it fulfills a Purpose for Users, as established in Why Deprecate, EWD1036, and The Best Code is No Code At All.

## Solutions

- Every level of the Development Stack above the chosen level has Evidence of the search performed.
- A Change reuses the Development Stack in Production code before introducing an External dependency.
