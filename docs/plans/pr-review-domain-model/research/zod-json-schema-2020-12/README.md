# JSON Schema Draft 2020-12 to Zod Derivation and Bundling

Research conducted on 2026-10-21 against `@sourcemeta/jsonschema@17.0.0`, `zod@4.6.7`, `x-to-zod@0.10.9`, and `json-schema-to-zod@2.8.1`.

## 1. JSON Schema Bundling (`@sourcemeta/jsonschema@17.0.0`)

| Topic | Verified behaviour | Source |
|---|---|---|
| `jsonschema bundle <file> -r schemas` | Produces a Draft 2020-12 Compound Schema Document by embedding external referenced schemas under root `"$defs"` keyed by their canonical `"$id"` URI while leaving `"$ref"` strings unchanged at call sites. | [command_bundle.cc](https://github.com/sourcemeta/jsonschema/blob/v17.0.0/src/command_bundle.cc), [Draft 2020-12 Core §9.3](https://json-schema.org/draft/2020-12/json-schema-core#section-9.3) |
| `jsonschema bundle --without-id -r schemas <file>` | Strips `"$id"` from root and embedded schemas and rewrites every external and embedded `"$ref"` into a single-document root-anchored RFC 6901 JSON Pointer (`#/$defs/https:~1~1thruput.se~1agents~1schemas~1review~1...`). | [command_bundle.cc#L121-L136](https://github.com/sourcemeta/jsonschema/blob/v17.0.0/src/command_bundle.cc#L121-L136) |

## 3. Architectural Conclusion for Contract-to-Domain Derivation

1. **Contract Bundling & Build Artifact (`build.sh`)**:
   - During `build.sh`, `@sourcemeta/jsonschema@17.0.0 bundle --without-id -r schemas` bundles each schema in `schemas/review/*.schema.json` (and `schemas/governance/*.schema.json`) and flattens RFC 6901 `#/$defs/...` pointers into self-contained JSON schemas (or generated `.mjs` Zod modules) under a gitignored directory `skills/pr-review/scripts/.generated/` (satisfying `[[No committing generated code]]` and eliminating `npx --yes @sourcemeta/jsonschema` subprocess spawns on every runtime call).
2. **Zod Schema Derivation & Perimeter Folding (`zod@4.6.7`)**:
   - `z.fromJSONSchema(bundledSchema)` constructs the exact Zod v4 validator from the contract.
   - Each domain module pairs its derived Zod schema with a `.transform(...)` / `.safeParse(...)` inside its named `[[Validating factory]]` (`fromRaw(raw)`), returning a typed `Result` (`Ok` / `Err`) in its signature (`[[Creation failure in the signature]]`) that folds the validated structure into a frozen (`Object.freeze(this)`), private-constructor (`#fields` + module-private `Symbol` guard) `[[Domain object]]` or `[[Domain primitive]]`.
