# Thruput Agents

Agentic workflows, engineering rules, and autonomous developer skills for Thruput.

## Overview

This repository defines the foundational quality principles, rules, and autonomous skills for AI agents operating across the Thruput ecosystem.

The governance architecture follows [ADR 0001](docs/adrs/0001-separating-principles-rules-and-standards.md).

## Foundation

- **[PRINCIPLES.md](PRINCIPLES.md):** Defines core software quality principles, mental models, and the trade-off hierarchy for resolving ambiguity.
